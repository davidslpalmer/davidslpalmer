## Selected projects

### [FRDb — Film Review Database](https://github.com/davidslpalmer/FRDb---Film-Review-Database-School-project-)

**PHP · JavaScript · HTML/CSS · SQLite · TMDb API · Open-Meteo API**

An IMDb-inspired web application with movie information, ratings, watchlists, user authentication, and role-based access. It combines movie and weather APIs to offer context-aware recommendations, including films for bad-weather days and outdoor activities when the weather is good.

### [Password Vault](https://github.com/davidslpalmer/password-vault)

**C# · .NET · AES · PBKDF2**

An educational command-line password manager exploring encrypted data storage and password-derived encryption keys. It supports creating a vault, storing and retrieving entries, generating passwords, and changing the master password. The repository also includes automated tests.

[Explore the implementation](https://github.com/davidslpalmer/password-vault)

### [Hotel Management Database System](https://github.com/davidslpalmer/hotel-database-system)

**SQL · SQLite · ER modeling · Database normalization**

Designed and implemented a relational database for a fictional hotel chain, progressing from conceptual ER diagrams through normalized relational schemas to a working SQLite database. The project models reservations, guests, rooms, services, and payments, with SQL queries supporting operational analysis.

[View database design and SQL examples](https://github.com/davidslpalmer/hotel-database-system)

### [Adverse Event Reporting System — Business Process & Requirements](https://github.com/davidslpalmer/bis-adverse-event-system)

**Requirements engineering · Process modeling · Conceptual system design**

An academic systems analysis project proposing an information system for reporting adverse drug reactions. The work connects business goals and process models to system requirements, with attention to validation, traceability, and reporting workflows.

### [CodEd — Digital Transformation Strategy](https://github.com/davidslpalmer/digital-transformation-coded)

**Digital transformation · IT requirements · Business processes · Change management**

A consultancy-style academic case study developing a digital transformation strategy for an education business.
