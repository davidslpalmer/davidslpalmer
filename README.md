## Selected projects

### [FRDb — Film Review Database](https://github.com/davidslpalmer/FRDb---Film-Review-Database-School-project-)

**PHP · JavaScript · HTML/CSS · SQLite · TMDb API · Open-Meteo API**

An IMDb-inspired web application for discovering and rating movies, maintaining watchlists, and exploring user profiles. FRDb includes authentication and role-based access, and combines movie data with weather information to recommend films on bad-weather days or outdoor activities when the weather is nice.
